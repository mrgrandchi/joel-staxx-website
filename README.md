# Joel Staxx Website

Official Joel Staxx artist website.

## Current status

Production frontend structure created from the approved website demo.

## Structure

- `index.html` — homepage
- `pages/` — future standalone site pages
- `css/` — organized stylesheets
- `js/` — frontend behavior
- `components/` — reusable UI components
- `assets/` — artist, release, video and merch media
- `data/` — editable music, video, update and merch content
- `docs/` — project documentation

## Deployment

Designed for Vercel deployment from the `main` branch.
